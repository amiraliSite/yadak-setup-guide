🖥️ راهنمای نصب و خروجی exe — پروژه‌ی یَدَک

از نصبِ صفرِ Flutter SDK و Visual Studio 2022 تا ساختِ فایلِ اجراییِ ویندوز (exe). قدم‌به‌قدم، با تمام جزئیات.

1 نصبِ Flutter SDK

فلتر، موتورِ اصلیِ ساختِ اپلیکیشن‌هایcross-platform است. برای خروجیِ exe، فقط به Flutter SDK و کامپایلرِ C++ مایکروسافت نیاز داریم.

مراحل

  1. به صفحه‌ی رسمی نصب برو:
https://docs.flutter.dev/get-started/install/windows/desktop
  1. دکمه‌ی Download Flutter SDK را بزن. فایلِ flutter_windows_X.X.X-stable.zip دانلود می‌شود.
  2. یک پوشه بساز مثلاً C:\src و زیپ را داخلش extract کن. پس از اکسترکت باید این مسیر باشد:
C:\src\flutter\bin\flutter.bat
⚠️ نکته‌ی مهم: Flutter را در مسیری با فاصله (space) یا کاراکتر فارسی نگذار. پوشه‌هایی مثل Desktop به‌خاطر OneDrive گاهی دردسر می‌سازند. بهترین مسیر: C:\src\flutter

افزودن به PATH

  • منوی استارت → تایپ کن env → Edit the system environment variables
  • دکمه‌ی Environment Variables… (پایین پنجره)
  • در بخش User variables، متغیر Path را پیدا کن → Edit
  • دکمه‌ی New → این مسیر را Paste کن:
C:\src\flutter\bin
  • سه OK را بزن تا بسته شود.

تست

یک CMD جدید باز کن (حتماً جدید، تا PATH بارگذاری شود) و بزن:

flutter --version

اگر نسخه‌ی فلتر را نشان داد ✓ نصب درست است

2 نصبِ Visual Studio 2022 (با C++)

این مهم‌ترین و حجیم‌ترین قسمت است. بدون این، flutter build windows اصلاً اجرا نمی‌شود. فلتر برای ساخت exe به کامپایلر C++ مایکروسافت (MSVC) و CMake نیاز دارد.

۲-۱) دانلود Visual Studio Installer

  1. به این آدرس برو:
https://visualstudio.microsoft.com/vs/community/
  1. دکمه‌ی Download Visual Studio → نسخه‌ی Community 2022 (رایگان). فایلِ VisualStudioSetup.exe دانلود می‌شود.
  2. فایل را اجرا کن.

۲-۲) انتخاب Workload (کلیدِ کل ماجرا)

وقتی Installer باز شد، پنجره‌ای با تب‌های Workloads / Individual components / Language packs ظاهر می‌شود. در تب Workloads تیکِ این کارت را بزن:

☑ Desktop development with C++
این کارت چه چیزی نصب می‌کند؟ با تیک زدنِ آن، خودِ Installer این‌ها را نصب می‌کند (لازم نیست دستی اضافه کنی):
  • MSVC v143 — کامپایلر C++ (واجب)
  • C++ CMake tools for Windows (واجب)
  • Windows SDK یا Windows 11 SDK (واجب)
  • C++ ATL و ابزارهای جانبی

۲-۳) تب Individual components (توصیه)

چک کن حداقل یکی از این‌ها تیک خورده باشد (معمولاً با همان workload خودش می‌آید):

  • Windows 11 SDK (10.0.22621.0) یا Windows 10 SDK
  • MSVC v143 - VS 2022 C++ x64/x86 build tools (latest)

۲-۴) نصب

  • مسیر نصب پیش‌فرض C:\Program Files\Microsoft Visual Studio\2022\Community را همان‌طور رها کن.
  • دکمه‌ی Install را بزن.
  • حجم دانلود حدود ۶ تا ۹ گیگ است. صبر کن تا تمام شود.
  • وقتی تمام شد، ازت Restart می‌خواهد → بزن.

۲-۵) لایسنس Community

اولین بار که VS باز شود ممکن است بخواهد وارد اکانت مایکروسافت شوی یا لایسنس Community را تأیید کنی. «Continue without code» را بزن کافی است. ما فقط به کامپایلر نیاز داریم، خود VS را باز نمی‌کنیم.

3 نصبِ Git (اگر نداری)

https://git-scm.com/download/win

فایل را دانلود و اجرا کن. همه‌ی گزینه‌ها را پیش‌فرض بگذار (همه‌ی Next را بزن). واجب نیست ولی به‌خاطر flutter pub get و آپدیت‌ها مفید است.

4 چک نهایی با flutter doctor

CMD یا PowerShell باز کن و بزن:

flutter doctor -v

برای خروجی exe فقط این دو خط واجب است که سبز باشند:

[√] Flutter
[√] Windows development (Visual Studio - develop Windows apps ...)
اگر نوشت [!] Visual Studio not installed: یعنی workload C++ را درست تیک نزدی. برگرد به بخش ۲-۲ و مطمئن شو Desktop development with C++ تیک خورده، سپس Install را بزن.
اگر نوشت [√] Windows ولی [!] Android Studio یا [!] Chrome: برای exe واجب نیستند، بی‌خیالشان شو.

5 آماده‌سازی پروژه‌ی یَدَک

  1. زیپِ آپدیت‌شده (yadak_full.zip) را extract کن روی مسیر پروژه. اگر قبلاً F:\Dev\yadak هست، محتوا را با overwrite/replace all روی آن کپی کن.
  2. CMD باز کن و به پوشه برو:
F:
cd \Dev\yadak
  1. وابستگی‌ها را دریافت کن:
flutter pub get
نکته‌ی کلیدی: پروژه فعلاً پوشه‌ی windows\ ندارد. پس باید آن را بسازی:
flutter create --platforms=windows .

آن نقطه (.) در انتهای دستور را فراموش نکن — یعنی «در همین پوشه». این دستور فایل‌های لازم (windows\runner\، CMake و…) را می‌سازد و به کدهای Dart تو دست نمی‌زند.

6 تنظیم عنوان پنجره (تیتل)

۶-۱) عنوان نوار پنجره

با Notepad یا VS Code این فایل را باز کن:

F:\Dev\yadak\windows\runner\main.cpp

خطی شبیه این را پیدا کن و "yadak_app" را تغییر بده:

if (!window.Create(L"مهر هلدینگ — مدیریت انبار", origin, size)) {

۶-۲) نام محصول در مشخصات فایل

این فایل را باز کن:

F:\Dev\yadak\windows\runner\Runner.rc
VALUE "ProductName", "مهر هلدینگ" "\0"

7 بیلد exe نهایی

در همان CMD (درون پوشه پروژه) بزن:

flutter build windows --release
اولین بار ممکن است ۳ تا ۸ دقیقه طول بکشد (CMake اولین بار همه‌چی را کش می‌سازد). دفعات بعد سریع‌تر است. اگر بدون خطا تمام شد ✓ exe ساخته شد

8 خروجی کجاست و چطور پخشش کنی

F:\Dev\yadak\build\windows\x64\runner\Release\

در این پوشه:

  • yadak_app.exe — فایل اجرایی اصلی
  • flutter_windows.dll — کتابخانه فلتر (لازم)
  • data\ — پوشه دارایی‌ها (لازم)
⚠️ بسیار مهم: فقط yadak_app.exe را کپی نکن! بدون flutter_windows.dll و data\ اجرا نمی‌شود. کل محتوای پوشه Release را کپی/Zip کن و ببر روی دستگاه مقصد.

می‌توانی نام yadak_app.exe را به مثلاً MehreHolding.exe تغییر دهی — به‌شرطی که dll و data کنارش بمانند.

9 نصب‌کننده MSIX (اختیاری)

اگر یک فایل نصب‌کننده (.msix) می‌خواهی که با دابل‌کلیک نصب شود:

flutter pub add dev:msix
flutter pub run msix:create

خروجی:

F:\Dev\yadak\build\windows\x64\runner\Release\yadak_app.msix

11 تغییر آیکون (اختیاری)

  1. یک آیکون 256×256 با نام app_icon.ico بساز.
  2. جایگزین کن با:
F:\Dev\yadak\windows\runner\resources\app_icon.ico
  1. دوباره flutter build windows --release.

🚀 خلاصه‌ی یک‌خطی

وقتی همه‌چی نصب است:

F:\Dev\yadak> flutter create --platforms=windows .
F:\Dev\yadak> flutter pub get
F:\Dev\yadak> flutter build windows --release

خروجی در: build\windows\x64\runner\Release\yadak_app.exe

از همه مهم‌تر: بخش ۲ (Visual Studio با C++) است — ۹۰٪ مواقع آدم‌ها همانجا گیر می‌کنند چون فقط flutter doctor می‌زنند و [!] Visual Studio not installed می‌بینند. workload Desktop development with C++ را حتماً تیک بزن.
